## ALU {#alu}
通过IP调用多个运算的核，再通过多路选择器。
有些需要取反的运算，比如减法，可以通过掩码来处理

!!! note "如何给ALU加上overflow"
    如果是加法，同号数相加，结果符号却不同
    ```verilog
    overflow = ~(A[31] ^ B[31]) & (A[31] ^ Y[31]);
    ```
    如果是减法，与A符号不同
    ```verilog
    overflow = ~(A[31] ^ B[31]) & (A[31] ^ Y[31]);
    ```



## Register Files {#register-files}
reg是数据通路部件，实现多位数据的读和写。verilog语言变量中的reg的电路实现则取决于具体逻辑，有可能是触发器，也有可能是锁存器等等 (~~数逻学的有点忘了。。。~~
时钟上升沿写入，rst置1是所有寄存器初始化为0
RISC-V 规定`x0` 是常数零寄存器，读它永远得到 0，写入它就丢弃

## 状态机 {#状态机}
实验要求设计一个检测特定序列（1110010）的状态机，这是一个Moore型，输出只和当前状态有关（与之相对的，Mealy型还与输入有关）

先画出状态转换图，再通过verilog设计（~~数逻还债x2~~

设计方法有一、二、三段式描述（几个always块的区别）这里我们采用三段式，即将输出信号,与状态跳转分开描述，并且状态跳转用组合逻辑来控制
