## 核心思想 {#核心思想}
ADT 的核心在于**“分离” (Separated)**。它把一个数据类型分成了两个层面：

*   **规格说明 (Specification)：** 解决“**是什么**”和“**做什么**”的问题。
    *   定义这个数据类型包含哪些对象（如：整数、字符、节点）。
    *   定义这些对象能进行哪些操作（如：插入、删除、查找）。
*   **实现/表示 (Representation / Implementation)：** 解决“**怎么做**”的问题。
    *   在计算机内存里到底用数组还是链表来存？（Representation）
    *   具体代码怎么写？（Implementation）

为什么要这么做？（ADT 的好处）
1.  **封装性 (Encapsulation)：** 保护了底层数据，用户不能乱改内部结构。
2.  **易维护性：** 如果发现用链表实现比数组更快，程序员可以偷偷把底层代码改了，而使用这个 ADT 的上层软件不需要改动任何一行代码。
3.  **简化问题：** 让软件开发人员可以专注于逻辑设计，而不需要每次都纠结于内存分配的细节。

## C语言实现 {#c语言实现}
- **typedef**
	- 灵活的数据类型
	  ```C
	  typedef int ElementType; // 以后想换类型，只需改这一行！
	  struct Node {
	      ElementType Data;    // 使用别名
	      struct Node *Next;
	  };
	  ```
	- 定义变量时不用再加上struct
	- 简化指针定义
	    ```C
	    typedef struct Node *PtrToNode; // PtrToNode 现在代表“指向 Node 结构体的指针”
		PtrToNode P; // 等价于 struct Node *P;
	    ```
	- 有时同一个struct可能会多次typedef
	  这是一种**“名字即注释”**的编程风格,如：

	| 类型名 | 含义 | 视角 |
	| :--- | :--- | :--- |
	| `struct Node` | 内存里的一个结构体块 | 硬件/内存 |
	| `PtrToNode` | 节点之间的连接线 | 程序员/算法实现 |
	| `Polynomial` | 一个完整的数学对象 | 用户/数学逻辑 |
- 结构体指针
	- 效率：只用传递一个地址，而不是整个结构体
	- 可以通过地址直接修改变量
	- 更符合malloc返回指针的习惯

### 链表(List) {#链表list}

!!! note
    实际上，链表和数组不是严格意义上的ADT，它是物理数据结构。所以，当我们描述后面的ADT的实现时，我们会说数组实现或是链表实现

####   游标实现（Cursor Implementation） {#游标实现cursor-implementation}
- 用“数组下标”代替“地址”：
在游标实现中，我们预先开辟一个大数组，`Next` 存的是下一个节点在数组中的**下标（Index）**

```c
#define SpaceSize 100

struct Node {
    ElementType Data;
    int Next; // 这里的 Next 是整数，不是指针！
};

struct Node CursorSpace[SpaceSize]; // 所有的节点都住在这个大数组里
```

- 如何管理空间？（备用链表 Freelist）
因为没有系统的 `malloc` 和 `free` 来自动分配内存，我们需要自己管理数组中哪些位置是空的，哪些是占用的。

	*   **备用链表 (Freelist)**：我们会把数组中所有**目前没被使用**的槽位也连成一个链表。
	*   **下标 0 的特殊作用**：通常习惯将 `CursorSpace[0]` 作为备用链表的头节点。它的 `Next` 指向第一个可用的空位。


- 模拟内存操作
可以把游标实现想象成一个**“小仓库”**：

*   **模拟 `malloc` (CursorAlloc)**：
    当需要新节点时，去下标 0 所在的“备用链表”里摘下一个空位。
*   **模拟 `free` (CursorFree)**：
    当删除节点时，不真正销毁，而是把这个位置的下标重新接回到“备用链表”中，留给下次使用。

- 意义何在？
	- 在某些单片机或嵌入式开发中，动态内存分配（malloc）非常昂贵且容易产生碎片。用游标实现在一块固定的静态内存里管理链表更安全、更可控。

#### 不同方式实现链表的比较 {#不同方式实现链表的比较}

| Operation | Sequential List | Doubly Linked List | Singly Circular | Doubly Circular |

### 栈(Stack) {#栈stack}

#### Specification {#specification}
- A stack is a **Last-In-First-Out (LIFO)** list, that is, an ordered list in which insertions and deletions are made at the **top only**.
- A finite **ordered** list with zero or more elements.

#### Implementation {#implementation}
 ##### Header
 ```C
#include <stdio.h>
#include <stdlib.h>
#define EmptyOS -1
#define MinStackSize 5

typedef int ElementType;

struct StackRecord {
    int Capacity;       // 栈的最大容量
    int TopOfStack;     // 栈顶索引 (空栈通常设为 -1)
    ElementType *Array; // 存放数据的数组
};

typedef struct StackRecord *Stack;
 ```

##### CreateStack {#createstack}
```C
Stack CreateStack(int MaxElements) {
    Stack S;

    if (MaxElements < MinStackSize)
        printf("Stack size is too small\n");

    S = malloc(sizeof(struct StackRecord)); /*先分配结构体的内存*/
    if (S == NULL)
        printf("Out of space!!!\n");

    S->Array = malloc(sizeof(ElementType) * MaxElements);
    if (S->Array == NULL)/*再分配结构体内部数组的内存*/
        printf("Out of space!!!\n");
        
    S->Capacity = MaxElements;
    MakeEmpty(S);

    return S;
}
```

##### IsEmpty {#isempty}
```C
int IsEmpty(Stack S) {
    return S->TopOfStack == EmptyOS;
}
```

##### MakeEmpty {#makeempty}
```C
void MakeEmpty(Stack S) {
    S->TopOfStack = EmptyOS;/*只需重置栈顶索引*/
}
```

##### Push {#push}
```C
void Push(ElementType X, Stack S) {
    if (S->TopOfStack == S->Capacity - 1) {
        printf("Stack is Full\n");
    } else {
        // 只有这里的代码可以访问 Array 和 TopOfStack
        S->Array[++S->TopOfStack] = X;
    }
}
```

##### Top {#top}
```C
ElementType Top(Stack S) {
    if (!IsEmpty(S)) {
        return S->Array[S->TopOfStack];
    }
    printf("Empty stack\n");
    return 0; // 返回错误标志
}
```
- 读取栈顶元素

##### Pop {#pop}
```C
void Pop(Stack S) {
    if (IsEmpty(S)) {
        printf("Empty stack\n");
    } else {
        S->TopOfStack--;
    }
}
```

##### DisposeStack {#disposestack}
```C
void DisposeStack(Stack S) {
    if (S != NULL) {
        free(S->Array); // 先释放内部数组
        free(S);        // 再释放结构体
    }
}
```


!!! note
    - The stack model must be well **encapsulated**.  That is, no part of your code, except for the stack routines, can attempt to access the Array or TopOfStack variable.
    - Error check must be done before Push or Pop (Top).


#### Three Expressions {#three-expressions}
- prefix & infix & postfix
###### 如何将三种表示方式互相转化 {#如何将三种表示方式互相转化}
- 抽象语法树（AST）（**将在树中详细展开** ）
	[树](%E6%A0%91.md#expression-trees)
  infix to postfix:[shunting-yard 算法](https://en.wikipedia.org/wiki/Shunting_yard_algorithm)
- 
| 转换方向 | 扫描方向 | 栈内存储内容 | 关键动作 |
| :--- | :--- | :--- | :--- |
| **中缀 $\rightarrow$ 后缀** | 从左向右 | **运算符** | 比较优先级，高的压栈，低的弹出 |
| **后缀 $\rightarrow$ 中缀** | 从左向右 | **操作数/子表达式** | 遇运算符弹出两个，组装 `(A op B)` |
| **前缀 $\rightarrow$ 中缀** | **从右向左** | **操作数/子表达式** | 遇运算符弹出两个，组装 `(A op B)` |
| **后缀 $\rightarrow$ 前缀** | 从左向右 | **子表达式** | 遇运算符弹出两个，组装 `op A B` |
- **ICP (Incoming Precedence)**：符号在**序列中（还没进栈）**时的优先级
 **ISP (In-Stack Precedence)**：符号已经**在栈顶**时的优先级
 - 通常左括号的ICP和ISP不同

#### 系统栈 (System Stack) {#系统栈-system-stack}
每当程序调用一个函数时，计算机都会在内存的一个特定区域（即**系统栈**）压入一个**栈帧（Stack Frame）**。
*   **栈帧里有什么？**
    *   **返回地址 (Return Address)**：告诉程序函数运行完后应该回到哪一行代码。
    *   **局部变量和参数**
    *   **寄存器信息**：当前的运行状态。
**关于递归**
- 尾递归与非尾递归：后者需要保留当前变量和地址，栈开销过大；而前者函数直接返回递归调用的结果，可以通过编译器的优化，只使用一层系统栈
- 递归都是可以避免的，但是递归可以提高代码的可读性

### 队列(Queue) {#队列queue}
#### Specification {#specification-1}
- A queue is a **First-In-First-Out (FIFO)** list, that is, an **ordered** list in which insertions take place at one end and deletions take place at the opposite end.
- A finite ordered list with zero or more elements.
#### Implementation {#implementation-1}
##### Header {#header}
```C
#include <stdio.h>
#include <stdlib.h>
#include <limits.h>

// 定义数据类型，可以根据需要修改
typedef int ElementType;

// 定义队列结构
struct QueueRecord {
    int Capacity;       // 队列总容量
    int Front;          // 队头下标
    int Rear;           // 队尾下标
    int Size;           // 当前队列中的元素个数
    ElementType *Array; // 存储元素的数组
};

typedef struct QueueRecord *Queue;

```
##### IsEmpty {#isempty-1}
```C

int IsEmpty(Queue Q) {
    return Q->Size == 0;
}
// 销毁队列
void DisposeQueue(Queue Q) {
    if (Q != NULL) {
        free(Q->Array);
        free(Q);
    }
}

```
##### IsFull {#isfull}
```C
// 检查队列是否已满（数组实现需要考虑满的情况）
int IsFull(Queue Q) {
    return Q->Size == Q->Capacity;
}
```

##### CreateQueue {#createqueue}
```C
// 创建队列
Queue CreateQueue(int MaxElements) {
    Queue Q;

    // 分配队列结构体内存
    Q = (Queue)malloc(sizeof(struct QueueRecord));
    if (Q == NULL) {
        printf(stderr, "Out of space!!!\n");
    }

    // 分配数组内存
    Q->Array = (ElementType *)malloc(sizeof(ElementType) * MaxElements);
    if (Q->Array == NULL) {
        printf(stderr, "Out of space!!!\n");
    }

    Q->Capacity = MaxElements;
    MakeEmpty(Q);

    return Q;
}
```

##### MakeEmpty {#makeempty-1}
```C
// 清空队列
void MakeEmpty(Queue Q) {
    Q->Size = 0;
    Q->Front = 1;
    Q->Rear = 0;
    // 注：初始化 Front > Rear 是为了让第一个入队元素放在下标 0 处
    // 因为 Enqueue 会先移动 Rear: Rear = (Rear + 1) % Capacity
}
```

##### Enqueue {#enqueue}
```C
// 入队
void Enqueue(ElementType X, Queue Q) {
    if (IsFull(Q)) {
        fprintf(stderr, "Full queue\n");
    } else {
        Q->Size++;
        // 循环移动队尾指针
        Q->Rear = (Q->Rear + 1) % Q->Capacity;
        Q->Array[Q->Rear] = X;
    }
}
```

##### Dequeue {#dequeue}
```C
// 出队
void Dequeue(Queue Q) {
    if (IsEmpty(Q)) {
        fprintf(stderr, "Empty queue\n");
    } else {
        Q->Size--;
        // 循环移动队头指针
        Q->Front = (Q->Front + 1) % Q->Capacity;
    }
}
```
##### ElementType {#elementtype}
```C
// 查看队头元素
ElementType Front(Queue Q) {
    if (!IsEmpty(Q)) {
        return Q->Array[Q->Front];
    }
    fprintf(stderr, "Empty queue\n");
    return 0; // 返回默认值
}
```

```C
// 出队并返回队头元素（可选）
ElementType FrontAndDequeue(Queue Q) {
    ElementType X = 0;
    if (IsEmpty(Q)) {
        fprintf(stderr, "Empty queue\n");
    } else {
        Q->Size--;
        X = Q->Array[Q->Front];
        Q->Front = (Q->Front + 1) % Q->Capacity;
    }
    return X;
}
```

##### Tag {#tag}
- 如果最后一次操作是 **Enqueue（入队）**，且 Front == Rear，队列一定是**满**的
- 如果最后一次操作是 **Dequeue（出队）**，且 Front == Rear，队列一定是**空**的
##### Absolute Counters {#absolute-counters}
- 这种方法不让 Front 和 Rear 在自增时立即取模，而是让它们一直增加，只有在访问数组下标时才取模

##### Size 字段法 {#size-字段法}
- Size == 0：队列一定为空
- Size == Capacity：队列一定为满
