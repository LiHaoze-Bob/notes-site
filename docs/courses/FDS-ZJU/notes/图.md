### 基础概念 {#基础概念}
- 有限的边集 $E=E(G)$ 和点集 $V=V(G)$
- 无向图（undirected graph）：边没有方向
- 有向图（directed graph）：边有方向
- 不考虑自环（self loop）和多重边（multigraph）
- 完全图（complete graph）：任意两个点之间都有边
- $v_i$ 和 $v_j$ 之间有一条无向边，则称：
    - $v_i$ 和 $v_j$ 相邻（adjacent）
    - $(v_i, v_j)$ is incident on(关联于) $v_i$ and $v_j$
- 有一条从 $v_i$ 到 $v_j$ 的有向边，则称：
    - $v_i$ is adjacent **to** $v_j$
    - $v_j$ is adjacent **from** $v_i$
    - $\langle v_i, v_j \rangle$ is incident on $v_i$ and $v_j$
- 子图（subgraph）：边集和点集都是原图的子集
- 路径、路径长度都不必多说
    - 简单路径（simple path）：路径上的点不重复
- 回路（cycle）：路径的起点和终点相同
- 对于无向图：
    - 如果存在一条从 $v_i$ 到 $v_j$ 的路径，则称 $v_i$ 和 $v_j$ 连通（connected）
    - 如果任意一对点都连通，则称这个无向图是连通的（connected graph）
    - 连通分量（connected component）：无向图的极大连通子图
- 树是联通的无环图
- DAG（directed acyclic graph）：有向无环图
- 对于有向图：
    - 如果存在一条从 $v_i$ 到 $v_j$ 的路径，则称 $v_i$ 可达（reachable）$v_j$
    - 如果任意一对点都可达，则称这个有向图是强连通的（strongly connected）
    - 强连通分量：有向图的极大强连通子图
    - 如果有向图不是强连通的，但它的基础图（边去掉方向得到的无向图）是连通的，则称这个有向图是弱连通的（weakly connected）
- 度数：
    - 对于无向图，节点 $v$ 的度数 $\text{degree}(v)$ 是与 $v$ 相邻的节点数
    - 对于有向图，节点 $v$ 的入度数 $\text{indegree}(v)$ 是以 $v$ 为终点的边数，出度数 $\text{outdegree}(v)$ 是以 $v$ 为起点的边数
    - 边数等于所有节点的度数之和除以 2

!!! tip
    实际上，在起点和终点相同的前提下，`回路`要求不能有相同的边，`圈`要求不能有相同的顶点，`环`一般是指`圈`，而不是`自环`


    $$\text{自环 (Loop)} \subseteq \text{圈 (Cycle)} \subseteq \text{回路 (Circuit)}$$


    图论的基本定理：**一个图含有回路，当且仅当它含有圈。**

    proof:必要性显然，充分性：若回路中没有相同顶点，那么它就是圈；若有相同顶点，那么取这个相同顶点作为新的回路。因为图的边和顶点是有限的，所以进行有限次操作后必然无相同顶点，即有圈。

    这似乎反直觉，为什么两个有包含关系的元素在存在性方面却等价？
    这是因为它们是拓扑结构关系，而不是分类学关系，我们可以基于良基偏序关系，通过极小元收缩来保证存在性

#### 图的表示 {#图的表示}
- 邻接矩阵：
    - 如果存在一条从 $v_i$ 到 $v_j$ 的边，则 $a_{ij}=1$，否则 $a_{ij}=0$
    - 对于非稠密图来说非常浪费空间
    - if $G$ is undirected, then the adjacency matrix of $G$ is symmetric, so we can save space by storing only half of the matrix using 1-D array.

- 邻接表：
    - 对于每个节点，存储一个链表来记录所有和它相临的节点
    - 对于无向图会将每个边存储两次
    - 对于有向图无法遍历入度，需要逆邻接表
    - For undirected G: $S$ = $n$ heads + $2e$ nodes  = $(n+2e)$ ptrs+$2e$ ints

- 十字链表 orthogonal list:
	- 专为有向图设计，为邻接表的延伸
	- 将起点、终点相同的边分别用链表储存

- 邻接多重表 adjacency multilist:
	- 为无向图设计，只用操作一次边
	- 将边的两个顶点都指向它们的边，形成多重的邻接表

- 带权图：
    - 邻接矩阵：$a_{ij}$ 存储边 $(v_i, v_j)$ 的权重
    - 邻接表：每个链表节点存储边的权重

### 拓扑排序 {#拓扑排序}
- AOV 网路(顶点活动网)：定点表示活动，边表示活动之间的先后关系
    - if feasible, then irreflexive: 可以实现的 AOV 网路一定是 DAG（有向无环图）
- 如果存在一条从 $i$ 到 $j$ 的路径，则称 $i$ 是 $j$ 的前驱（predecessor），$j$ 是 $i$ 的后继（successor）
- 如果存在一条边 $\langle i, j \rangle$，则称 $i$ 是 $j$ 的直接（immediate）前驱，$j$ 是 $i$ 的直接后继
- 拓扑排序（topological order）是一个图的点集的线性序列，满足：
    - 对于任意一对点 $i, j$，如果 $i$ 是 $j$ 的前驱，则序列中 $i$ 在 $j$ 的前面

```c
void topsort(Graph G) {
    Queue Q = CreateQueue(); 
    int cnt = 0; Vertex V, W;
    for (each vertex V)
        if (indegree[V] == 0) Enqueue(Q, V);
    while (!IsEmpty(Q)) {
        V = Dequeue(Q); 
        TopNum[V] = ++cnt;
        for (each W adjacent to V)
            if (--indegree[W] == 0) Enqueue(Q, W);
    }
    if (cnt != NumVertex) Error("Graph has a cycle");
    free(Q);
}
```

### 最短路算法 {#最短路算法}


!!! tip
    邻接表or邻接矩阵？
    对于顶点树小的图，实际上差不多，邻接矩阵实现更方便。但是若数据量大，则用邻接表。若是floyd算法，则用邻接矩阵。

#### 单源最短路 {#单源最短路}
给定一个有向图和一个源点，求从源点到图中每个点的最短路径


!!! note
    If there is no negative-cost cycle, the shortest path from s to s is defined to be zero.


##### 无权图 {#无权图}
```c
void Unweighted( Table T )
{ /* 假设表 T 已经用给定的源顶点 S 完成了初始化 */
    Queue  Q;
    Vertex  V, W;
    
    // 创建一个容量为 NumVertex 的队列并清空
    Q = CreateQueue( NumVertex );  MakeEmpty( Q );
    
    // 1. 将源顶点 S 入队
    Enqueue( S, Q ); /* Enqueue the source vertex */
    
    // 2. 核心循环：只要队列不为空，就继续处理
    while ( !IsEmpty( Q ) ) {
        V = Dequeue( Q ); // 出队一个顶点 V
        
        T[ V ].Known = true; /* 注：此步骤在无权 BFS 中并非绝对必要 */
        
        // 3. 遍历与 V 邻接的所有顶点 W
        for ( each W adjacent to V )
            
            // 如果 W 尚未被到达过（距离为无穷大）
            if ( T[ W ].Dist == Infinity ) {
                T[ W ].Dist = T[ V ].Dist + 1; // W 的距离在 V 的基础上加 1
                T[ W ].Path = V;               // 记录 W 的前驱节点为 V
                Enqueue( W, Q );               // 将 W 入队，等待后续处理它的邻接点
            } /* end-if Dist == Infinity */
            
    } /* end-while */
    
    DisposeQueue( Q ); /* 释放队列内存，防止内存泄漏 */
}
```
- $T = O(|V| + |E|)$
- 三元表格：最短长度、访问标记、路径追踪
- 通过队列可以优化，因为队列可以存储状态改变的节点，不用每次都遍历全部；而且不用访问标记数组

##### 带权图 {#带权图}

!!! algorithm "Dijkstra算法"
    1. 数学符号定义
    * 设 **$S = \{ s \text{ 且所有已找到最短路径的顶点 } v_i \}$**。
    * 对于任何不在 $S$ 中的顶点 $u \notin S$，定义 **$\text{distance}[u]$** 为满足以下路径形式的**最小路径长度**：


       $$\{ s \to (v_i \in S) \to u \}$$


       即：从源点 $s$ 出发，只经过 $S$ 中的顶点作为中转站，最后到达 $u$ 的最短路径。

    2. 核心原理

    ① 路径局限性定理
    从 $s$ 到任何 $u \notin S$ 的当前最短路径，其中转顶点**必须全部属于 $S$**（即 $\text{ONLY } v_i \in S$）。

    ② 贪心选择定理 
    我们每一次选择的下一个加入 $S$ 的顶点 $u$，必须满足：


    $$\text{distance}[u] = \min_{w \notin S} \{ \text{distance}[w] \}$$


    （如果满足最小值的 $u$ 不唯一，可以任选其中一个）。

    **Why?**
    * **反证法证明**：如果当前选出的 $\text{distance}[u]$ 不是实际的最短路径，那么必然存在另一条更短的路径。这条更短的路径在离开 $S$ 集合时，必然要经过某个同样不在 $S$ 中的中间顶点 $w \notin S$。
    * 由于我们选出的 $u$ 已经满足了 $\text{distance}[u] \le \text{distance}[w]$，且图的边权均为非负数，因此任何经过 $w$ 到达 $u$ 的路径长度必定 $\ge \text{distance}[w] \ge \text{distance}[u]$。
    * 从而产生矛盾，证明当前选出的 $u$ 的距离就是最终的最短路径。

    ③ 松弛操作 / Relaxation
    如果 $\text{distance}[u_1] < \text{distance}[u_2]$，并且我们把 $u_1$ 加入到集合 $S$ 中。此时，未确定的顶点 $u_2$ 的最短距离可能会发生改变。
    如果发生了改变，那么从 $s$ 到 $u_2$ 的新的更短路径**必定经过 $u_1$**，新的距离更新为：


    $$\text{distance}'[u_2] = \text{distance}[u_1] + \text{length}(\langle u_1, u_2 \rangle)$$




###### implementation1:数组 {#implementation1数组}
```c
#include <stdbool.h>

#define INF  999999  // 表示无穷大
#define NONE -1      // 表示无前驱

// 顶点表结构
typedef struct {
    int Dist;        // 最短距离
    int Path;        // 前驱节点
    bool Known;      // 确定标记
} TableEntry;

// 1. 顺序扫描：在未收录顶点中寻找距离最小者，时间复杂度 O(V)
static int FindMin(TableEntry T[], int N) {
    int min_v = NONE, min_d = INF;
    for (int i = 0; i < N; i++) {
        if (!T[i].Known && T[i].Dist < min_d) {
            min_d = T[i].Dist;
            min_v = i;
        }
    }
    return min_v;
}

// 2. Dijkstra Implementation 1 核心算法，时间复杂度 O(V^2)
void Dijkstra(TableEntry T[], int N, int Adj[N][N], int Start) {
    // 初始化 Table
    for (int i = 0; i < N; i++) {
        T[i].Dist = INF;
        T[i].Path = NONE;
        T[i].Known = false;
    }
    T[Start].Dist = 0;

    while (true) {
        int V = FindMin(T, N); // 顺序扫描寻找最小顶点
        if (V == NONE) break;  // 所有顶点已收录或不可达，退出

        T[V].Known = true;     // 收录顶点 V

        // 更新 V 的所有未知邻接点 W
        for (int W = 0; W < N; W++) {
            int Cvw = Adj[V][W];
            if (Cvw != INF && Cvw != 0 && !T[W].Known) { // 0表示自环，INF表示不连通
                if (T[V].Dist + Cvw < T[W].Dist) {
                    T[W].Dist = T[V].Dist + Cvw; // 松弛操作 (Decrease)
                    T[W].Path = V;
                }
            }
        }
    }
}
```

- $T(N) = O(|V|^2 + |E|)$，good if the graph is dense

###### implementation2:堆优化 {#implementation2堆优化}
针对find the smallest unknown distance vertex优化
method1:DecreaseKey
method2:LazyDeletion
由于1过于复杂，采用method2:
```c
// 堆节点结构
typedef struct {
    int v;               // 顶点编号
    int dist;            // 对应的距离
} HeapNode;

// 最小堆结构
typedef struct {
    HeapNode data[MAX_HEAP];
    int size;
} MinHeap;

// 1. 最小堆：上滤操作 O(log V)
static void Push(MinHeap *pq, int v, int dist) {
    int i = ++(pq->size);
    while (i > 1 && pq->data[i / 2].dist > dist) {
        pq->data[i] = pq->data[i / 2];
        i /= 2;
    }
    pq->data[i].v = v;
    pq->data[i].dist = dist;
}

// 2. 最小堆：下滤操作 (DeleteMin) O(log V)
static HeapNode Pop(MinHeap *pq) {
    HeapNode min_node = pq->data[1];
    HeapNode last_node = pq->data[(pq->size)--];
    int i = 1, child;
    while (i * 2 <= pq->size) {
        child = i * 2;
        if (child != pq->size && pq->data[child + 1].dist < pq->data[child].dist)
            child++;
        if (last_node.dist > pq->data[child].dist)
            pq->data[i] = pq->data[child];
        else
            break;
        i = child;
    }
    pq->data[i] = last_node;
    return min_node;
}

// 3. Dijkstra 堆优化算法核心
void Dijkstra(TableEntry T[], int N, int Adj[N][N], int Start) {
    // 初始化 Table T
    for (int i = 0; i < N; i++) {
        T[i].Dist = INF;
        T[i].Path = NONE;
        T[i].Known = false;
    }
    T[Start].Dist = 0;

    MinHeap pq = { .size = 0 };
    Push(&pq, Start, 0); // 起点入队

    while (pq.size > 0) {
        // V = smallest unknown distance vertex (通过 DeleteMin 快速获取)
        HeapNode node = Pop(&pq);
        int V = node.v;

        // 【关键点】：Method 2 要求持续 DeleteMin，直到弹出一个未确定的顶点
        if (T[V].Known) continue; 
        T[V].Known = true;

        // 遍历所有邻接点 W
        for (int W = 0; W < N; W++) {
            int Cvw = Adj[V][W];
            if (Cvw != INF && Cvw != 0 && !T[W].Known) {
                if (T[V].Dist + Cvw < T[W].Dist) {
                    T[W].Dist = T[V].Dist + Cvw;
                    T[W].Path = V;
                    
                    // Method 2: 直接将更新后的 W 插入堆中，允许节点重复
                    Push(&pq, W, T[W].Dist); 
                }
            }
        }
    }
}
```
$T(N) =  O(E \log V)$,good if the graph is sparse
$S(N) = O(|E|)$

##### 有向无环图（DAG） {#有向无环图dag}
 $T = O(|E| + |V|)$
 no priority queue is needed


!!! application "AOE"
    每个节点存在一个最早完成时间（earliest completion time）$EC[v]$ 和最晚完成时间（latest 
    completion time）$LC[v]$。两者均通过[图](#%E6%8B%93%E6%89%91%E6%8E%92%E5%BA%8F)计算，前者从起点开始拓扑排序，后者从终点开始。

    如何确定终点：可以通过出队后压入栈中实现，或者将所有出度为0的节点引向一个虚拟终点

    每条边存在一个持续时间（lasting time）也就是边权 $C$，还有一个松弛时间（slack time）
    $EC[w] = \max_{\langle v, w \rangle \in E} \{ EC[v] + C_{v, w} \}$
    $LC[v] = \min_{\langle v, w \rangle \in E} \{ LC[w] - C_{v, w} \}$
    边 $\langle v, w \rangle$ 的松弛时间为 $LC[w] - EC[v] - C_{v, w}$



!!! algorithm "CPM"
    关键路径（critical path）为全是 0 松弛时间的边构成的路径
    关键路径的长度即是完成整个流程的最小时间
    $T(N) = S(N) = O(|V| + |E|)$

##### method2:Floyd算法 {#method2floyd算法}


$$T = O(|V|^3)$$


- 支持负权边并可以找出负权环

```c
int dist[N][N];        // 距离矩阵（初值为图的邻接矩阵）
int path[N][N];        // 路径矩阵（用于记录和重建路径）

// Floyd-Warshall 核心算法，时间复杂度 O(V^3)，空间复杂度 O(V^2)
void FloydWarshall(int NumVertex) {
    // 1. 初始化路径矩阵
    for (int i = 0; i < NumVertex; i++) {
        for (int j = 0; j < NumVertex; j++) {
            if (dist[i][j] != INF && i != j) {
                path[i][j] = i; // 初始化前驱
            } else {
                path[i][j] = -1;
            }
        }
    }

    // 2. 三重循环（关键点：控制中转站的循环 k 必须在最外层）
    for (int k = 0; k < NumVertex; k++) {          // k 代表允许作为中转站的顶点
        for (int i = 0; i < NumVertex; i++) {      // i 代表起点
            for (int j = 0; j < NumVertex; j++) {  // j 代表终点
                
                // 防止溢出的安全松弛操作
                if (dist[i][k] != INF && dist[k][j] != INF) {
                    if (dist[i][k] + dist[k][j] < dist[i][j]) {
                        dist[i][j] = dist[i][k] + dist[k][j]; // 状态转移
                        path[i][j] = path[k][j];              // 更新前驱
                    }
                }
                
            }
        }
    }
}
```
### 网络流 {#网络流}
- 最大流：给定一个有向图，求从源点到汇点的最大流量
- 建立残差图（residual graph），设 $f$ 是图 $G=(V, E)$ 的一个流量，则残差图的边权为：


$$
c_f(u, v) = \begin{cases} 
c(u, v) - f(u, v) & \text{if } (u, v) \in E \\
f(v, u) & \text{if } (v, u) \in E \\
0 & \text{otherwise}
\end{cases}
$$


- 找残差图中从源点到汇点的一条简单路径，称为增广路（augmenting path）
- 增广路的流量为增广路上的最小边权，创建这样一条流量，更新残差图，直到找不到增广路为止


!!! algorithm "Ford-Fulkerson Algorithm"
    对于当前流 $G_f$ 中任意一条流量为 $f_{v, w}$ 的有向边 $(v, w)$，在残量网络 $G_r$ 中增加一条反向边 $(w, v)$，其容量也设为 $f_{v, w}$。
    - If the edge capabilities are rational numbers, this algorithm always terminate with a maximum flow.
    - The algorithm works for G with cycles as well.

    若寻找增广路径使用随机的顺序，可能会出现极端的情况，$T(N) = O(f*|E|)$
    所以，我们使用最大堆优化的`Dijkstra算法`，寻找瓶颈流量的最大值
    此时 


$$T(N) = T_{\text{augmentation}} \times T_{\text{find a path}} = O(|E| \log cap_{\max}) * O(|E| \log |V|) = O(|E|^2 \log cap_{\max} \log |V|)$$




!!! algorithm "Edmonds-Karp Algorithm"
    寻找增广路径时采用最少边的方法，可以用无权图的单源最短路的队列方法，此时为纯粹的强多项式时间


    $$T(N) = O(|V| + |E|) * O(|E| * |V|) = O(|E|^2|V|)$$


    - 如果所有流量都是1，那么使用二分图最大匹配或者其他算法，时间复杂度为$O(|E|^2|V|^{0.5})$
    - min-cost flow问题要求在保证最大流的同时，找到代价最低的路径



### 最小生成树 {#最小生成树}
- 最小生成树（minimum spanning tree）是给定一个连通图，找一个总边权最小的生成树
    - 生成树为图的一个子图，包含所有点，且任意两点之间有且仅有一条边
- 连通图iff存在一个最小生成树
- 向生成树中添加一个额外的边，则一定会存在一个环
- Prim 算法（二叉堆实现） 

$$T = O(|E| \log |V|)$$


    ```text
    T = 最小权边
    for i = 1..n-2
        e = 与 T 中的点相连且加入 T 后不会形成环的最小权边
        将 e 加入 T
    T 即为最小生成树
    ```
- Kruskal 算法 

$$T_{\text{Kruskal}} = O(|E| \log |V|)$$


    ```text
    T = 空图
    for i = 1..n-1
        e = 加入 T 中不会形成环的最小权边
        将 e 加入 T
    T 即为最小生成树
    
    ```
    - 可以通过并查集来维护
        1. 建立并查集
        2. 将边按照权值从小到大排序
        3. 从小到大遍历所有边，若两个端点不在同一集合，则将两个端点合并，将边加入 T；在同一集合中则忽略

### 深度优先搜索 {#深度优先搜索}
- 深度优先搜索（depth-first search，DFS）是一种用于遍历或搜索树或图的算法
- 是先序遍历的一种推广
    ```c
    void dfs(Vertex V) {
        Visited[V] = true;
        for (each W adjacent to V)
            if (!Visited[W]) dfs(W);
    }
    ```
- 双连通性
    - 如果去掉一个点，剩下的图不再是连通的，则称这个点为割点（cut vertex），或 articulation point
    - 如果图 $G$ 是连通的，并且没有 articulation point，则称 $G$ 是双连通的
    - 双连通分量（biconnected component）是极大的双连通子图
    - Tarjan 算法
        - $dfn[x]$ 表示 $x$ 第一次被访问的时间戳（dfs 时第几个被访问，从 0 开始）
        - 追溯值 $low[x]$
            - 初始 $low[x] = dfn[x]$
            - 对于从 $x$ 到 $y$ 的边，如果 $\langle x, y \rangle$ 在搜索树上，则 $low[x] = \min(low[x], low[y])$
            - 如果 $\langle x, y \rangle$ 不在搜索树上，则 $low[x] = \min(low[x], dfn[y])$
        - 找割点
            - 如果 $u$ 是 root，则 $u$ 是割点当且仅当 $u$ 有至少两个dfs儿子
            - 如果 $u$ 不是 root 则 $u$ 是割点当且仅当存在一个儿子 $v$，满足 $dfn[u] \le low[v]$
- 欧拉回路与欧拉路径
    - 欧拉回路（Euler circuit）为包含所有边的简单环，欧拉路径（Euler path）为包含所有边的简单路径
    - 无向图
        - 无向图 $G$ 有欧拉回路当且仅当 $G$ 是连通的且每个顶点的度数都是偶数
        - 无向图 $G$ 有欧拉路径当且仅当 $G$ 是连通的且有且仅有两个顶点的度数是奇数
    - 有向图
        - 有向图 $G$ 有欧拉回路当且仅当 $G$ 是弱连通的且每个顶点的出度等于入度
        - 有向图 $G$ 有欧拉路径当且仅当 $G$ 是弱连通的且有且仅有一个顶点的出度比入度大 1，有且仅有一个顶点的入度比出度大 1，其余顶点的出度等于入度
    - dfs 即可
```c
void dfs(int x) {
    for (int y = 1; y <= maxn; ++y) {
        if (G[x][y]) {
            G[x][y] = 0;
            G[y][x] = 0;
            dfs(y);
        }
    }
    ans[++ansi] = x;
    return;
}
```
