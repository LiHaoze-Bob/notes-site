## 算法与分析 {#算法与分析}

- 一个定义好的、计算机可执行的、解决某一问题的有限步骤
- 需要有以下特征：
    - Input
    - Output
    - Definiteness
    - Finiteness
    - Effectiveness
- program 不需要 finite（比如操作系统）
- 算法分析内容：
    - 运行时间（Machine & compiler-dependent run times)：与机器和编译器有关
    - 时间复杂度、空间复杂度(Time & space complexities: machine & compiler-independent)：与机器和编译器无关
- 复杂度分析假设
    - 指令按顺序执行
    - 所有指令（运算）都消耗同一时间单元

!!! note "CMP & MOV"
    - MOV指在 CPU 内部总线上触发电压信号，将电荷状态从一组触发器（寄存器）复制到另一组。
    - CMP做减法运算，但不保存减法结果。目的是改变CPU的状态标志寄存器，然后紧跟一个跳转指令
    - 时间复杂度往往由CMP决定，所以当我们计算具体操作次数时，我们通常只计算comparison，不计算arithmetic operations

    - 数据规模是给定的，且有无限空间
- 一般需要分析 $T_{\mathrm{avg}}(N)$（平均情况）和 $T_{\mathrm{worst}}(N)$（最差情况），$N$ 是输入的数据规模（也可以有多个输入规模）

## 复杂度渐进记号 {#复杂度渐进记号}
### 定义 {#定义}
- 大 $O$ 表示法 $T(N) = O(f(N))$，如果存在常数 $c$ 和 $n_0$ 使得当 $N\geq n_0$ 时 $T(N)\leq c\cdot f(N)$
    - 渐进上界，即 $T(N)$ 的阶不会高于 $f(N)$（增长比 $f(N)$ 慢或相同，<=）
- 大 $\Omega$ 表示法 $T(N) = \Omega(g(N))$，如果存在常数 $c$ 和 $n_0$ 使得当 $N\geq n_0$ 时 $T(N)\geq c\cdot g(N)$
    - 渐进下界，即 $T(N)$ 的阶不会低于 $f(N)$（增长比 $f(N)$ 快或相同，>=） 
- 大 $\Theta$ 表示法 $T(N) = \Theta(h(N))$，当且仅当 $T(N) = O(h(N))$ 且 $T(N) = \Omega(h(N))$
    - 渐进紧确界，即 $T(N)$ 需要与 $h(N)$ 同阶（增长速度相同 =）
- 小 $o$ 表示法 $T(N) = o(p(N))$，当 $T(N) = O(p(N))$ 且 $T(N)\ne \Theta(p(N))$ 时
    - 非渐进紧确上界（$T(N)$ 增长比 $p(N)$ 慢，<）
- 小 $\omega$ 表示法 $T(N) = \omega(p(N))$，当 $T(N) = \Omega(q(N))$ 且 $T(N)\ne \Theta(q(N))$ 时
    - 非渐进紧确下界（$T(N)$ 增长比 $q(N)$ 快，>）

### 规则 {#规则}
- 如果 $T_1(N) = O(f(N))$ 且 $T_2(N) = O(g(N))$，则：
    - $T_1(N) + T_2(N) = \mathrm{max}(O(f(N)), O(g(N)))$
    - $T_1(N)\cdot T_2(N) = O(f(N)\cdot g(N))$
- 如果 $T(N)$ 是 $N$ 的 $k$ 次多项式，则 $T(N) = \Theta(N^k)$
- 对于任意常数 $k$ 均有 $\log^kN = O(N)$
- 大 O 记号比较：[Big O Cheat Sheet](https://www.bigocheatsheet.com/)
- 分析规则：
    - for 循环的运行时间是循环内部语句的最长时间（含 for 判断）乘循环次数
    - 嵌套 for 循环要逐次相乘
    - if else 语句的运行时间不超过判断时间+耗时最长的语句块的运行时间
    - for loop要注意1的加减
#### 如何通过递推式求解复杂度 {#如何通过递推式求解复杂度}
- **主定理**
	假设有 $T(n) = aT(n/b)+f(n)$（$a\geq 1, b>1$），则：
    - 如果存在常数 $\epsilon > 0$ 有 $f(n) = O(n^{\log_ba-\epsilon})$，则 $T(n) = \Theta(n^{\log_ba})$
    - 如果 $f(n) = \Theta(n^{\log_ba})$ 则 $T(n) = \Theta(n^{\log_ba}\log n)$
    - 如果存在常数 $\epsilon > 0$ 有 $f(n) = \Omega(n^{\log_ba+\epsilon})$，同时存在常数 $c<1$ 使得对于充分大 $n$ 有 $af(n/b)\leq cf(n)$ 则 $T(N) = \Theta(f(n))$
- 递归树法
- 数列递推
	  ** 本质** ：数列求通项
- Akra-Bazzi 方法 —— **主定理的“终极增强版”**


## 一些降低复杂度的算法 {#一些降低复杂度的算法}
### 最大子序列和问题 {#最大子序列和问题}
#### O(N³) {#on3}
直接枚举开头结尾，并计算中间子序列和：
```c 
int MaxSubsequenceSum(const int a[], int N) {
    int res = 0;
    for (int i = 0; i < N; ++i) {
        for (int j = i; j < N; ++j) {
            int now = 0;
            for (k = i; k <= j; ++k) {
                now += a[k];
            }
            res = max(res, now);
        }
    }
    return res;
} 
```
#### O(N²) {#on2}
同样枚举开头结尾，不过动态计算子序列和，省去最内层循环
```c
int MaxSubsequenceSum(const int a[], int N) {
    int res = 0;
    for (int i = 0; i < N; ++i) {
        int now = 0;
        for (int j = i; j < N; ++j) {
            now += a[j];
            res = max(res, now);
        }
    }
    return res;
}
```
#### O(NlogN) {#onlogn}
使用分治算法



$$
\begin{align*}
T(N) &= 2T(N/2)+cN,\quad T(1) = O(1) \\
&= 2\left(2T(N/2^2)+cN/2\right)+cN \\
&= 2^kO(1) + ckN\qquad\text{where }N/2^k=1 \\
&= O(N\log N)
\end{align*}
$$



#### O(N) {#on}
动态规划思想
```c
int MaxSubsequenceSum(const int a[], int N) {
    int res = 0, now = 0;
    for (int i = 0; i < N; ++i) {
        now += a[i];
        res = max(res, now);
        now = max(now, 0);
    }
    return res;
}
```

### Euclid's Algorithm {#euclids-algorithm}

- **用途：** 求两个正整数的最大公约数（GCD - Greatest Common Divisor）。  
- **别名：** 辗转相除法。

#### 核心思想： {#核心思想}
 - gcd(a,b)=gcd(b,a(modb))
#### 时间复杂度： {#时间复杂度}

- **O(log⁡(min⁡(a,b)))**
- **直观理解**：每执行两步，较大的那个数至少会减小一半以上。它的最坏情况发生在一对**斐波那契数**上   
- **如何证明**：拉梅定理（Lamé's Theorem）<https://en.wikipedia.org/wiki/Lam%C3%A9%27s_theorem>








## 幂运算 / 快速幂 (Exponentiation / Fast Powering) {#幂运算-快速幂-exponentiation-fast-powering}

#### 快速幂做法（分治法）： {#快速幂做法分治法}
利用指数的数学性质：
1.  如果 $n$ 是**偶数**：$a^n = (a^{n/2})^2$
2.  如果 $n$ 是**奇数**：$a^n = a \times (a^{(n-1)/2})^2$

#### 递归逻辑（这就是主定理的应用场景）： {#递归逻辑这就是主定理的应用场景}
```c
long int Power(int a, int n) {
    if (n == 0) return 1;
    if (n == 1) return a;
    if (isEven(n)) 
        return Power(a * a, n / 2); // 偶数情况
    else 
        return Power(a * a, n / 2) * a; // 奇数情况
}
```

#### 时间复杂度分析： {#时间复杂度分析}
*   **递归方程**：$T(n) = T(n/2) + O(1)$（注：每次规模减半，只做一次乘法）。
*   **主定理应用**：$a=1, b=2, f(n)=1$。根据 Case 2，复杂度为 **$O(\log n)$**。
斐波那契数列的第 $n$ 项，最快的方法也是利用矩阵形式的**快速幂**（复杂度也是 $O(\log n)$）。

#### 更加优化 {#更加优化}
```C
unsigned long long fast_pow(unsigned long long a, unsigned long long b, unsigned long long m) {
    unsigned long long res = 1;
    a %= m; //实际工业界中m会设定为2的幂次，使得%m可以转化为位运算
    
    while (b) {            // 优化 1：省去 b > 0 的判断，直接判定非零
        if (b & 1) {       // 优化 2：按位与取代 b % 2 != 0，1 个指令周期
            res = (res * a) % m;
        }
        a = (a * a) % m;
        b >>= 1;           // 优化 3：逻辑右移取代 b / 2，1 个指令周期
    }
    return res;
}```
