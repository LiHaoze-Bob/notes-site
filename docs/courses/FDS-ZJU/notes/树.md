### 基础概念 {#基础概念}
--- 
- 树包括根节点（root），0 个或多个非空子树 $T_1,\cdots, T_k$ 与根通过一条有向边连接
- 每棵子树的根叫做 root 的儿子（children），root 是每棵子树根的父亲（parent）
- 一棵树是 $N$ 个节点和 $N-1$ 条边的集合
- 没有儿子的节点称为树叶（leaf or terminal node）
- 有相同父亲的节点称为兄弟（siblings）
- 节点的儿子数量称为这个节点的度（degree）
- 一棵树的度是这棵树里所有节点度的最大值
- 从节点 $n_1$ 到 $n_k$ 的路径是唯一的，其长度是路径上边的数量
- 对于节点 $n_i$，其深度为从根到 $n_i$ 的唯一路径的长度
- 对于节点 $n_i$，其高度为从 $n_i$ 到一个叶节点的最长长度
- 根的高度称为这棵树的高度/深度
- 一个节点的祖先（ancestors）是从根到这个节点的路径上的所有节点
- 一个节点的后裔（descendants）是这个节点子树中的所有节点

### 树的表示 {#树的表示}
--- 
- 列表表示
    - 子节点个数未知，不易表示
- FirstChild-NextSibling 表示法
    - 记录第一个子节点和下一个兄弟节点
    - 因为一棵树的儿子顺序不定，所以一棵树的表示方式不唯一


### Expression Trees {#expression-trees}
---
- 特征：leaves存储operands，internal nodes存储operators
#### 核心逻辑 {#核心逻辑}
- 在于 **二元操作符（Binary Operator）的结构属性** 和 **树的序列化（Serialization）**

##### 1. 表达式的本质：递归定义 {#1-表达式的本质递归定义}
一个二元表达式 $E$ 可以递归定义为：


$$E = (E_{left}) \text{ op } (E_{right})$$


或者是一个原子操作数（如常数 $c$ 或变量 $x$）。

##### 2. 遍历的本质：位置约定 {#2-遍历的本质位置约定}
二叉树遍历是对二维结构进行“线性化（Flattening）”的过程。**前、中、后序**的区别仅仅在于：**操作符（根节点）相对于它的操作数（子树）放在哪里。**

*   **前序遍历（Root -> L -> R）**：约定先写操作符，再写左操作数，最后右操作数。
    *   数学形式：$\text{op } E_{L} E_{R}$
    *   这就是 **前缀表达式（波兰表达式）**。它的好处是符合“函数式”思维，像 `add(a, b)`。
*   **中序遍历（L -> Root -> R）**：约定操作符放在中间。
    *   数学形式：$E_{L} \text{ op } E_{R}$
    *   这就是 **中缀表达式**。它是人类习惯的表达方式。
    *   *数学难点*：由于中序遍历在降维时丢弃了树的层级信息（括号），所以中缀表达式具有歧义，必须引入“优先级”和“括号”来补全。
*   **后序遍历（L -> R -> Root）**：约定先写完所有操作数，最后写操作符。
    *   数学形式：$E_{L} E_{R} \text{ op }$
    *   这就是 **后缀表达式（逆波兰表达式）**。

##### 3. 底层数学原理：堆栈与确定性 {#3-底层数学原理堆栈与确定性}
*   **计算模型**：前缀和后缀表达式（波兰/逆波兰）在数学上是 **“无括号”且“无歧义”** 的。
*   **确定性有限自动机**：从数学证明上，后序遍历对应的后缀表达式可以通过一个简单的**下推堆栈（Pushdown Stack）**在一次扫描中计算完成，不需要看后续项。这就是为什么编译器内部喜欢把代码转成后缀序的原因——它在数学上是最简洁、执行路径最确定的。

#### 应用 {#应用}
- 它把符号运算变成了对树的**递归变换**，求导（Differentiation）在数学上本身就是一套递归规则



### 二叉树 {#二叉树}
---
- 二叉树（binary tree）是每个节点最多有两个儿子的树
- 每棵树都可以用二叉树来表示
    - 即通过 FirstChild-NextSibling 表示法
    - 将 FirstChild 视为左儿子，NextSibling 视为右儿子
- 完全二叉树（complete binary tree）是所有叶节点都在相邻的两层上的二叉树
    - 除了最后一层，每一层都是满的
    - 最后一层的节点都靠左排列
- 第 $i$ 层的节点数最多为 $2^{i-1}$
- 深度为 $k$ 的二叉树最多有 $2^k - 1$ 个节点
- $n_0$ 表示叶节点数，$n_2$ 表示度为 2 的节点数，则 $n_0 = n_2 + 1$

??? proof


    $$
    \begin{cases}
    n = n_0 + n_1 + n_2 \\
    n = B + 1 \\
    B = n_1 + n_2 * 2 \\
    \end{cases}
    $$


    - B represents the number of branches.

- 二叉树可以通过数组来表示（base1）
    - 根为 $tree[1]$
    - 节点 $tree[i]$ 的左儿子为 $tree[2i]$，右儿子为 $tree[2i+1]$
    - 完全二叉树的数组中元素全部分布在 1 ~ n 中

#### 遍历 {#遍历}
- 先序遍历（preorder traversal）
    - 根 -> 左 -> 右
- 后序遍历（postorder traversal）
    - 左 -> 右 -> 根
- 中序遍历（inorder traversal）
    - 左 -> 根 -> 右
    - 只适用于二叉树（可使用**LCRS**对N叉树进行转化）
    - 迭代写法
        ```c
        void iter_inorder(tree_ptr tree) {
            Stack S = create_stack();
            for (;;) {
                for (; tree; tree = tree->left)
                    push(S, tree);
                tree = top(S); pop(S);
                if (!tree) break;
                visit(tree->element);
                tree = tree->right;
            }
        }
        ```
- 层序遍历（level order traversal）
    - 从上到下，从左到右
    ```c 
    void levelorder(tree_ptr tree) {
        enqueue(tree);
        while (queue is not empty) {
            visit(T = dequeue());
            for (each child C of T) 
                enqueue(C);
        }
    }
    ```

### 线索二叉树 {#线索二叉树}
- 为了**更容易遍历**、**合理的栈开销**
- 如果一个节点的左儿子为空，那么它的左指针指向它的中序遍历前驱节点
- 如果一个节点的右儿子为空，那么它的右指针指向它的中序遍历后继节点
- 一定有一个 head node，左儿子为根，右儿子为自身
```c
typedef struct ThreadedTreeNode {
    int         LeftThread;  // 标志位：如果是 TRUE(1)，表示 Left 是线索；如果是 FALSE(0)，表示是左孩子
    ThreadedTree Left;        
    ElementType  Element;     
    int         RightThread; // 标志位：如果是 TRUE(1)，表示 Right 是线索；如果是 FALSE(0)，表示是右孩子
    ThreadedTree Right;       
}
```

### 二叉搜索树 {#二叉搜索树}
---
- 二叉搜索树（binary search tree）是一种二叉树，非空情况下服从以下性质：
    - 所有节点都有不同的 key（一个整数）
    - 一个节点的左子树的所有节点的 key 都小于这个节点的 key
    - 一个节点的右子树的所有节点的 key 都大于这个节点的 key
    - 左子树和右子树也都是二叉搜索树
- 二叉搜索树的中序遍历是有序的
- 查找
    - 从根节点开始，如果 key 小于当前节点的 key，就往左子树找，否则往右子树找
    - 直到找到 key 相等的节点，或者找到空节点
    - 时间复杂度 $O(h)$，$h$ 为树的高度，即 $O(\log n)$
- 查询最小值：遍历到最左边的节点
- 查询最大值：遍历到最右边的节点
- 插入
    - 从根节点开始，如果 key 小于当前节点的 key，就在左子树递归插入，大于就在右子树递归插入
    - 直到找到空节点，然后插入
    - 或者找到相同的 key，忽略
    - 时间复杂度 $O(h)$，$h$ 为树的高度，即 $O(\log n)$
- 删除
    - 删除叶节点：直接删除即可
    - 删除只有一个儿子的节点：直接删除，然后把儿子接上
    - 删除有两个儿子的节点
        - 将该节点替换为左子树的最大值，或右子树的最小值
        - 递归删除左子树的最大值，或右子树的最小值

##### Find {#find}
```c
Position Find(ElementType X, SearchTree T) {
    if (T == NULL)
        return NULL; // 未找到
    if (X < T->Element)
        return Find(X, T->Left);
    else if (X > T->Element)
        return Find(X, T->Right);
    else
        return T;    // 找到
}
```
- NULL代表地址0，而其不允许被访问
- $T(N) = S(N) = O(d)$, where $d$ is the depth of $X$

##### FindMin {#findmin}
- 最好像Findmax一样用迭代，但是尾递归可优化
```c
Position FindMin(SearchTree T) {
    if (T == NULL)
        return NULL;
    else if (T->Left == NULL)
        return T;
    else
        return FindMin(T->Left);
}
```

##### FindMax {#findmax}
```c
Position FindMax(SearchTree T) {
    if (T != NULL)
        while (T->Right != NULL)
            T = T->Right;
    return T;
}
```

##### Insert {#insert}
```c
SearchTree Insert(ElementType X, SearchTree T) {
    if (T == NULL) {
        /* 创建并返回单节点树 */
        T = malloc(sizeof(struct TreeNode));
        if (T == NULL) {
            fprintf(stderr, "Out of space!!!\n");
            exit(1);
        }
        T->Element = X;
        T->Left = T->Right = NULL;
    } else if (X < T->Element) {
        T->Left = Insert(X, T->Left);
    } else if (X > T->Element) {
        T->Right = Insert(X, T->Right);
    }
    /* 如果 X 已经存在，则什么都不做 */
    return T;
}
```
- $T(N) = O(d)$
##### Delete {#delete}
```c
SearchTree Delete(ElementType X, SearchTree T) {
    Position TmpCell;

    if (T == NULL) {
        printf("Element not found\n");
    } else if (X < T->Element) { /* 向左找 */
        T->Left = Delete(X, T->Left);
    } else if (X > T->Element) { /* 向右找 */
        T->Right = Delete(X, T->Right);
    } else if (T->Left && T->Right) { /* 找到节点，且有两个孩子 */
        /* 用右子树的最小值填充当前节点 */
        TmpCell = FindMin(T->Right);
        T->Element = TmpCell->Element;
        /* 删除那个被用来填充的重复节点 */
        T->Right = Delete(T->Element, T->Right);
    } else { /* 找到节点，且有一个或零个孩子 */
        TmpCell = T;
        if (T->Left == NULL) /* 有右孩子或无孩子 */
            T = T->Right;
        else if (T->Right == NULL) /* 有左孩子 */
            T = T->Left;
        free(TmpCell);
    }
    return T;
}
```
- 也可以填充左子树的最大结点，若多次操作同一边，可能会导致树的平衡性不好

##### Lazy Deletion {#lazy-deletion}
- 重新插入快，不改变树的拓扑结构
- 空间浪费，查找逻辑变复杂，遍历变慢
- 可以通过rebuild重构

!!! success
    - 假设活跃节点有 $N$ 个，总节点数（含已删除）就是 $2N$。
        *   在平衡的情况下，树的高度 $h \approx \log_2(\text{总节点数})$。
        *   $h_{new} = \log_2(2N) = \log_2 N + 1$。
    *   **结论：** 只要树本身是相对平衡的，50% 的懒惰删除比例**不会严重影响**基本操作的效率

### 线段树 (Segment Tree) {#线段树-segment-tree}

- 处理区间查询和元素修改

| 数据结构     | 区间查询 (Query)    | 修改 (Update)                |
| :------- | :-------------- | :------------------------- |
| **普通数组** | $O(n)$          | $O(1)$                     |
| **前缀和**  | $O(1)$          | $O(n)$ (修改一个点后，后面的前缀和都要重算) |
| **线段树**  | **$O(\log n)$** | **$O(\log n)$**            |

#### Build {#build}
找终点，然后逐层分裂 。近似于完全二叉树，所以可以推出空间复杂度，但是我们实际上会开$4N$的数组(base1)
```c

void Build ( int node, int start, int end )  //node初始值通常赋为1
{
    // Base Case: Leaf Node
    // 基准情况：叶子节点
    if ( start == end ) {
        tree[ node ] = A[ start ];
        return;
    }

    // Recursive Step: Split and Build Children
    // 递归步骤：分裂区间并构建子节点
    int mid = ( start + end ) / 2;
    Build ( 2 * node, start, mid );           // 构建左孩子
    Build ( 2 * node + 1, mid + 1, end );     // 构建右孩子

    // Merge Logic: Sum of children
    // 合并逻辑：父节点的值等于两个子节点之和
    tree[ node ] = tree[ 2 * node ] + tree[ 2 * node + 1 ];
}
```
$S(N) = O(2N - 1)$   $T(N) = O(N)$

#### Query {#query}
```c
/**
 * 线段树区间查询
 * @param node  当前节点的下标
 * @param start 当前节点管理的区间起点
 * @param end   当前节点管理的区间终点
 * @param L     目标查询区间的左边界
 * @param R     目标查询区间的右边界
 * @return      返回查询范围内的总和
 */
int Query ( int node, int start, int end, int L, int R )
{
    // Case 1: No Overlap (Node is completely outside query range)
    // 情况 1：无重叠（当前节点管理的区间完全在查询范围之外）
    if ( R < start || end < L ) {
        return 0;
    }

    // Case 2: Total Overlap (Node is completely inside query range)
    // 情况 2：完全包含（当前节点管理的区间完全在查询范围之内）
    if ( L <= start && end <= R ) {
        return tree[ node ];
    }

    // Case 3: Partial Overlap (We need to go deeper into both children)
    // 情况 3：部分重叠（需要递归进入左右子节点继续查询）
    int mid = ( start + end ) / 2;
    int left_sum  = Query ( 2 * node, start, mid, L, R );
    int right_sum = Query ( 2 * node + 1, mid + 1, end, L, R );

    return left_sum + right_sum;
}
```
$T(N) = O(logN)$
#### Update {#update}
```c
/**
 * 线段树单点修改
 * @param node  当前节点的下标
 * @param start 当前节点管理的区间起点
 * @param end   当前节点管理的区间终点
 * @param idx   要修改的目标元素在原数组中的下标
 * @param val   要修改的新值
 */
void Update ( int node, int start, int end, int idx, int val )
{
    // Base Case: Leaf Node found
    // 基准情况：找到了叶子节点（即原数组 A[idx] 对应的节点）
    if ( start == end ) {
        tree[ node ] = val;
        return;
    }

    // Recursive Step: Go left or right depending on where "idx" is
    // 递归步骤：根据 idx 的位置决定进入左子树还是右子树
    int mid = ( start + end ) / 2;
    if ( start <= idx && idx <= mid ) {
        // Index is in the left child
        // 目标索引在左子区间
        Update ( 2 * node, start, mid, idx, val );
    } else {
        // Index is in the right child
        // 目标索引在右子区间
        Update ( 2 * node + 1, mid + 1, end, idx, val );
    }

    // Backtracking Step: Update current node based on new children values
    // 回溯步骤：根据子节点的新值更新当前父节点的值
    tree[ node ] = tree[ 2 * node ] + tree[ 2 * node + 1 ];
}
```
$T(N) = O(logN)$

#### Aggregation Operator {#aggregation-operator}
线段树适用于任何区间聚合运算符，即满足**结合律**（即 $(a \circ b) \circ c = a \circ (b \circ c)$），实际上要求维护一个幺半群（单位元是一个与其他区间合并不产生变化的元素）

如`XOR`、`MIN`、`MAX`、`Average`(需要区间长度数组)、`GCD`

#### Lazy Propagation {#lazy-propagation}

区间修改优化为$O(logN)$，其他保持不变
##### push_down {#push_down}
```c
#define MAXN 100005
long long tree[4 * MAXN];
long long lazy[4 * MAXN]; // 存储懒标记

// 将标记下传给子节点
void push_down(int node, int start, int end) {
    if (lazy[node] != 0) {
        int mid = (start + end) / 2;
        
        // 更新左孩子的值和标记
        tree[2 * node] += lazy[node] * (mid - start + 1);
        lazy[2 * node] += lazy[node];
        
        // 更新右孩子的值和标记
        tree[2 * node + 1] += lazy[node] * (end - mid);
        lazy[2 * node + 1] += lazy[node];
        
        // 清除当前节点的标记
        lazy[node] = 0;
    }
}
```

!!! important
    左孩子的区间是$[start, mid]$
    右孩子的区间是$[mid+1,end]$ 

##### RangeUpdate {#rangeupdate}
```c
// 区间修改：将 [L, R] 范围内的数全部加上 val
void RangeUpdate(int node, int start, int end, int L, int R, int val) {
    // 1. 完全包含：打标记，不继续递归
    if (L <= start && end <= R) {
        tree[node] += (long long)val * (end - start + 1);
        lazy[node] += val;
        return;
    }
    
    // 2. 部分重叠：下传标记，递归子树
    push_down(node, start, end);
    
    int mid = (start + end) / 2;
    if (L <= mid) RangeUpdate(2 * node, start, mid, L, R, val);
    if (R > mid)  RangeUpdate(2 * node + 1, mid + 1, end, L, R, val);
    
    // 3. 回溯更新父节点
    tree[node] = tree[2 * node] + tree[2 * node + 1];
}
```
##### RangeQuery {#rangequery}
```c
// 带懒标记的查询
long long RangeQuery(int node, int start, int end, int L, int R) {
    if (R < start || end < L) return 0;
    if (L <= start && end <= R) return tree[node];
    
    // 查询前也必须下传标记，确保子节点数据是最新的
    push_down(node, start, end);
    
    int mid = (start + end) / 2;
    return RangeQuery(2 * node, start, mid, L, R) + 
           RangeQuery(2 * node + 1, mid + 1, end, L, R);
}
```

### Quiz 1 {#quiz-1}
**已知前序遍历（Preorder）和中序遍历（Inorder）构建二叉树**。
#### 1. 核心原理 {#1-核心原理}
*   **前序遍历**：第一个元素永远是当前的**根节点**。
*   **中序遍历**：根节点将序列分为两部分，左边是**左子树**，右边是**右子树**。

**递归逻辑：**
1. 从前序遍历序列中取出当前节点作为根。
2. 在中序遍历中找到该节点的位置，确定左、右子树的边界。
3. 递归地构建左子树。
4. 递归地构建右子树。

---

#### 2. 伪代码 {#2-伪代码}

```pseudocode
function buildTree(preorder, inorder, inStart, inEnd):
    if (inStart > inEnd) return NULL
    
    // 1. 从前序遍历中获取当前根节点的值
    rootValue = preorder[preIndex++]
    root = createNode(rootValue)
    
    // 2. 在中序遍历中寻找根节点的位置
    pivot = search(inorder, inStart, inEnd, rootValue)
    
    // 3. 递归构建左右子树
    // 注意：必须先左后右，因为前序遍历的顺序是 根->左->右
    root.left = buildTree(preorder, inorder, inStart, pivot - 1)
    root.right = buildTree(preorder, inorder, pivot + 1, inEnd)
    
    return root
```
